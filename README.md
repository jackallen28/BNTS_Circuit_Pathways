# Circuit Pathways: drafts

**This branch is not the product.** It keeps older and experimental work, organised, so the `main` branch can hold
only the current Circuit Pathways website. Nothing here is deployed, and none of it is tested by CI.

For the real thing, go to the **`main`** branch.

Everything lives in [`draft/`](draft/README.md), which says what each folder is, where it came from, and what
state it was left in.
