Teachers: start a class

Sign in with your teacher code to make a class code for your students, and to save a class file.

Only a first name and a school are asked for, and they stay in your own saved file in this browser. They are never sent to or kept on our server.

Two apps, one way of learning

Adaptive, not generative

No generative AI. Help adapts to each student, using hints written and checked by teachers.

Choose your help

Beginner, Moderate or Advanced. Students can change it any time.

A Coach for every error

Errors are explained in plain English, with hints that start small.

One part at a time

Test each part on its own, then join it up. Checklists tick themselves.

Simulator first

Try it on the on-screen board, then on real hardware.

Saved on your computer

Work saves in the student's browser, and they can keep it as a file.
