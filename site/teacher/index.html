1. Make a class code

Give this code to your students. They type it on the Circuit Pathways home page, then use their own first name and school. Nothing about your class is kept on our server: the code works because of how it is made.

A class code can't be switched off early, so pick a length that suits the program. Make a new one any time.

2. Class file and student work

A class file (.circuitclass) is saved on your computer, never on our server. It holds the class details and any student work you add, so you can open the class again later.

Student work

Students save their own work with Settings > Save my work and give you their .circuit (ArduinoPath) or .pipath (PiPath) files. Add them here to see who has done what.
