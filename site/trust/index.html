Set up this computer for Circuit Pathways

Circuit Pathways runs on your school's own server. To upload to a board, and for Python programs that ask questions, your browser needs the server's secure address (https). Do this once on each computer, then use the secure address.

2. Trust it

Windows (Chrome or Edge)
  1. Open the file you downloaded (circuit-pathways-school.crt) and press Install Certificate...
  2. Choose Current User (no administrator needed) and press Next.
  3. Choose Place all certificates in the following store, press Browse..., pick Trusted Root Certification Authorities, then OK and Next.
  4. Press Finish, then Yes to the security warning.
  5. Close every Chrome or Edge window, then open the secure address.
Mac
  1. Open the file you downloaded. Keychain Access opens: add it to the login keychain.
  2. In Keychain Access, double-click Circuit Pathways school server, open Trust, and set When using this certificate to Always Trust. Close it and type your Mac password.
  3. Quit Chrome or Edge, then open the secure address.
Chromebook
  1. Open chrome://certificate-manager (type it in the address bar).
  2. Under Local certificates (or Authorities), press Import, pick the file, and tick Trust this certificate for identifying websites.
  3. Open the secure address.
For IT: every laptop at once

Deploy the certificate to the Trusted Root Certification Authorities store with Intune or Group Policy (or the Google Admin console for Chromebooks). It is limited (name constraints) to .local names and private network addresses, so it can't vouch for any internet site.

Instead of the certificate, the Chrome / Edge policy OverrideSecurityRestrictionsOnInsecureOrigin with http://pathways.local also works (uploading and Python work on the plain address).
